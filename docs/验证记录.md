## 验证边界

- 自动化截图只包含单个应用窗口，不能单凭它断言跨应用的前后叠放关系，因此全屏效果明确采用用户的肉眼确认，不把单窗口截图作为叠放证明。
- 正倒计时切换、暂停排除、超时与保存的数值正确性由自动化测试验证；没有为每一种状态都做逐帧人工视觉验收。
- 最终 `dist/悬浮计时.app` 在已打开的版本上增加了“内容变化才刷新”、避免相同数据重复写盘、狭窄尺寸下的按钮布局约束。已重新编译和执行相关测试；为保留用户正在运行的计时，没有强制退出旧进程。
- 未在 Intel Mac、多显示器、台前调度、独占全屏游戏上实测，也未故意让用户的 Mac 睡眠或强制终止进程来测试。睡眠暂停已接入系统事件，恢复行为有模型测试。
- 不声称能够覆盖锁屏、系统安全界面或一切其他高层级窗口。

## 复现命令

```sh
bash scripts/build.sh
bash scripts/test.sh
bash scripts/build-fixture.sh
```

前两条生成最终应用并检查计时逻辑。第三条仅生成独立的全屏测试应用，不是日常使用所需。

可在退出当前计时器后双击 `dist/悬浮计时.app`，确认恢复为暂停，位置、尺寸和最近记录仍保留。
