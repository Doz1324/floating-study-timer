# 应用图标

用户确认的方向：A＋黑白。深灰圆角方形底、白色极简秒表（圆、一根指针、顶部小按钮）；不加文字、数字、渐变或立体装饰。

工具：内置 image_gen，单张新图生成，透明外边距。原图保存在同目录的 AppIcon.png；通过 macOS sips 缩放到标准尺寸，再由 iconutil 打包为 ../AppIcon.icns。没有修改计时逻辑或学习记录。
